# video-pipeline

Automation for Everyday Case Study, a faceless YouTube channel of case studies on how the world really works: business, technology, cities, history and the news, one real story at a time.
Plan: [docs/YouTube-Automation-Guide-Book.md](docs/YouTube-Automation-Guide-Book.md).
Setup checklist: [docs/Setup-Guide.md](docs/Setup-Guide.md).

## Commands

| Command | What it does |
| --- | --- |
| `npm run draft` | For the row set to **Go**: Claude researches a sourced brief and writes the script into its Notion page, then sets it to **Script Ready**. |
| `npm run scenes` | For the row set to **Approved**: turns the script into `media/<video>/scenes.json` (one visual per 8–12 s) plus `narration.txt`: money-flow diagrams, source documents, charts, maps, numbers, titles and footage. Quotes shown on screen must appear word for word in the brief, or they're dropped, and each document card is titled with its source's real headline from the brief's Sources list, so viewers can find it. Refuses if `[bracketed notes]` are left in the narration. |
| `npm run voice` | For the **Approved** row with scenes: the narrator reads `narration.txt` (ElevenLabs, one paragraph per request) into `media/<video>/narration.wav`, plus `timing.json` with when every scene, sentence and word starts. The narration is sped up 1.12× (about 170 words a minute), with longer gaps between chapters and a beat before any paragraph marked `[pause]` or `[long pause]`; those are settings at the top of `src/voice.mjs`, and changing them costs no credits. Add `--sample` to voice just the first three paragraphs. Needs a paid ElevenLabs plan for a library voice. Ends with `npm run listen`. |
| `npm run listen` | Checks the narration says what the script says: Whisper (`brew install whisper-cpp`; its 574 MB model downloads on first use) transcribes `narration.wav` on this Mac in about 35 seconds, the transcript is lined up against the script word by word, and Claude (about $0.03) sorts the differences into misreads (a wrong number, a skipped or added word, an abbreviation read out wrong) and ones that are only Whisper spelling a word its own way. Prints what to listen to, with times, and saves a 7-second clip of each to `media/<video>/listen/`. Results in `listen.json`. |
| `npm run music` | Builds just the background music, and `render/music-preview.m4a` (narration and music, no picture) to listen to. `npm run render` does this too. Claude gives each part of the script a mood (about $0.05), keeping any one mood to about 5 minutes; tracks of that mood from `media/music/<mood>/` (`curious`, `tense`, `somber`, `hopeful`) play under it, crossfading where the mood changes, about 17 dB under the narration, rising a little in the pauses between parts and under the end screen. Levels are settings at the top of `src/music.mjs`. A track added by hand that needs a credit gets a `.txt` beside it with the credit line, listed in `music.json`. With no tracks, videos render without music. |
| `npm run music:library` | Composes the music library with ElevenLabs Music: 12 instrumental tracks of 2.5 minutes, three per mood, described in `src/music-library.mjs`. Only missing tracks are composed, so delete one you don't like and run it again for a new take. Writes `media/music/sampler.m4a`, ten seconds of each. The Creator plan includes 62 minutes of music a month and allows commercial use with no credit; tick YouTube's "altered or synthetic content" box when uploading (it doesn't affect monetization). The API key needs the Music permission. |
| `npm run footage` | For the **Approved** row with scenes: for each stock and image scene, gathers Pixabay videos and photos, Wikimedia Commons videos and photos of the real places named and, for scenes about the past, old film from the Internet Archive (Prelinger Archives, US government films and Universal Newsreels, only those marked public domain, CC0 or CC BY, since many Prelinger films are still under copyright), has Claude pick the best from a still of each, and downloads it to `media/<video>/footage/`. A Commons or Archive video is shown to Claude as numbered stills, one per uninterrupted stretch (so it can skip interviews, reporters and title cards), and only the chosen stretch is downloaded, with black borders cropped off. Each aerial scene becomes a zoom from about 50 km up down onto the real town, or onto a named site in it, which gets circled, using public-domain US aerial imagery (USDA NAIP, via USGS The National Map) and places looked up on OpenStreetMap; if the place can't be found, it looks for a photo instead. Clips tagged with horror or a place outside the US, and scanned maps offered as photos of a place, are filtered out first. A scene where nothing fits holds the shot right before it, or gets a short text card. `footage.json` keeps the runners-up and the credits the description needs. |
| `npm run render` | For a row with narration and footage: Remotion (`remotion/`) assembles the video (footage, money-flow diagrams, source documents, charts, big numbers, title cards, US maps of the real places, hand-drawn pen marks) into `media/<video>/render/<video>.mp4`, ending with a 12-second hold for YouTube's end screen, plus `<video>.srt` captions to upload with it (long videos have no burned-in captions), and moves the row to **Review**. `--preview 120` renders 30 seconds from 2:00; `--studio` opens Remotion Studio to scrub through it. The look (colors, fonts) is in `remotion/theme.js`. |
| `npm run package` | For a rendered row: puts everything for the upload in `media/<video>/package/`. `upload.txt` lists every field YouTube Studio asks for, in its order, with the text to paste: five title options (each the question the video answers), the description, tags, settings, subtitles, end screen and the pinned comment from the Notion page. Beside it are `video.mp4` and `captions.srt` (linked from `render/`, not copied) and three thumbnails rendered in the videos' look, each made to say what the video is about at a glance: a headline naming the subject across the top, one bright photo filling the frame or two side by side as a contrast (real photos or aerial views from the video, the site circled; never stock or share-alike), and a callout: a number tag or a receipt with one line circled. Thumbnail claims must be as strong as the narration makes them, measuring the same thing. The description gets chapters from the narration's timing, every credit the licenses ask for, and as many sources as fit in 5,000 characters (on-screen ones first; all are in `sources.txt`). Edit `package.json` and add `--keep-words` to rebuild without Claude. About $0.12. |
| `npm run channel-art` | Renders the profile picture (two takes) and banner into `media/channel/`, in the videos' palette and fonts. |
| `npm run check` | Tests every key in `.env` and checks n8n and git. Never prints keys. |
| `npm run notion:setup` | Creates the Notion **Videos** table with the first 10 ideas and saves its IDs to `.env`. |
| `npm run n8n:up` / `n8n:down` | Starts or stops n8n at http://localhost:5678 (Docker Desktop must be open). |
| `npm run n8n:logs` | Follows n8n's logs. |

Run `npm install` once after cloning (Node 22+).

## How a video moves

1. Set a row's Status to **Go** in Notion → `npm run draft`.
2. On the row's page, fact-check the brief's key numbers and its quotes (they appear on screen word for word), read the script, edit anything → set **Approved** (checkpoint 1). A paragraph starting with `[pause]` gets a beat of silence before it (the draft puts one before the biggest reveals); add or remove them freely. The script asks viewers one question to answer in the comments, and the **Pinned comment** section at the end holds the comment to pin under the video; edit either as you like. Notes (`>` lines) are never read aloud.
   - Fixed a fact in the brief, or want another take? `npm run draft -- "<title words>" --script-only` writes a new script from the brief on the page (about $0.50). The old one isn't lost: it moves to an **Earlier script, draft N** section at the bottom of the page, edits and pinned comment included. Only the section called **Script** is narrated, so to go back to an earlier draft, swap the two headings' names.
   - Edited a script outside Notion? `npm run draft -- "<title words>" --from-file=edited.md` puts it on the page as a new draft the same way, without calling Claude.
3. `npm run scenes`. It first tidies any lines you changed or added (typos, shorthand, symbols) and updates them on the Notion page, printing a before/after for each, then plans the scenes.
4. `npm run voice`, then play the clips the narration check lists (or listen through `narration.wav`). To fix a misread, respell the word in the script (like "Route 52" for "US 52"), then rerun `scenes` and `voice`; only that paragraph is paid for again. ElevenLabs charges per character: the 15-minute Walmart script took about 5,800 credits on the Creator plan.
5. `npm run footage` (about $0.90 of Claude), then `npm run render` (about 20 to 30 minutes for 15 minutes of video).
6. Watch the render once (checkpoint 2). To swap a clip, copy one of the scene's alternates in `footage.json` into its `"pick"`, run `npm run footage` to download it, and render again. Paragraphs already voiced are reused, so after fixing a line, rerun `scenes` and then `voice`, and only the changed paragraphs are paid for.
7. `npm run package`, then open `package/upload.txt` and follow it top to bottom in YouTube Studio.

Claude's prompts are in `src/prompts/` — edit `channel.md` to change the channel's voice and standards.

## Layout

- `.env`: your keys (gitignored). Template: `.env.example`.
- `src/`: the pipeline stages and their prompts.
- `remotion/`: the video template: one component per scene type, captions, and the theme.
- `media/`: voiceovers, stock clips and renders. Gitignored, and mounted into n8n at `/files`.
- `scripts/`: setup helpers.
- `docs/`: the plan and the setup guide.
